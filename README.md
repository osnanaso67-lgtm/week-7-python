# PLP Python Week 7 – Working with Files

This assignment practises opening files safely with `with open(...)`, writing, appending and reading text files, reading a CSV into a list of dictionaries, and handling a missing file without crashing.

## Files

- `my_notes.py` – writes three notes to a file, appends a fourth, reads them back with no blank lines, and counts the lines.
- `my_notes.txt` – the file generated by `my_notes.py` (4 notes).
- `report_builder.py` – reads `hubs.csv`, counts passed/failed learners, calculates the average score and writes `report.txt`; prints `hubs.csv not found` if the file is missing.
- `hubs.csv` – the learner data (name, hub, score) used by the report builder.
- `report.txt` – the report generated by `report_builder.py`.

## Question: what if `"a"` were changed to `"w"` in Question 1?

Mode `"w"` overwrites the file, so the second `open` call would erase the first three notes and leave only "I added this later". The program would then print just one note and `Total lines: 1` instead of 4.
